## Organização

Os projetos são mantidos em repositórios independentes e conectados a este projeto por meio de **Git Submodules**.

Isso permite:

- Manter cada projeto com seu próprio ciclo de desenvolvimento;
- Separar responsabilidades;
- Versionar componentes individualmente;
- Evitar um monorepo excessivamente acoplado;
- Integrar projetos distintos em um único ecossistema;
- Preservar projetos privados sem expor seu código-fonte.

```text
Projetos_Pessoais/
│
├── Projeto A → Submodule
├── Projeto B → Submodule
├── Projeto C → Submodule
├── Projeto D → Submodule
└── ...
```
